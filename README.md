# Quorum — Privacy Policy

Hosted copy of the privacy policy for **Quorum for iOS** (`com.wsig.Quorum`).

- Published: https://willsigmon.github.io/quorum-legal/
- Source of truth: `index.html` is generated from `privacy.md` with `./build.sh`
  (needs pandoc). Edit `privacy.md`, run the script, and commit both.
- The app itself makes no network request in its default demo mode, and has no
  accounts, analytics, ads, tracking, or third-party SDKs.
